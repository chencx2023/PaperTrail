# T02 搜索标注规则

`known_relevant` 是查询运行前冻结的小型已知相关集合，用来检查确定应当能找到的论文是否进入前 20；它不是领域的完整真值集，也不能据此计算完整召回率。匹配统一使用不带版本号的 arXiv ID，`2303.11366v2` 与 `2303.11366` 视为同一论文。

已知相关论文 Recall@20 定义为“前 20 条命中的已知相关论文数 / 本题已知相关论文数”。Precision@10 必须在看到结果后，依据该题的 `relevance_definition` 阅读标题和摘要逐条判断；不能因为一篇返回论文不在 `known_relevant` 中就把它标成不相关。少于十条时，Precision@10 的空位按未命中计；同时另报“相关数 / min(10, 实际返回数)”。

冻结后不根据本轮结果修改原问题、查询词、相关性定义或种子论文。事实错误可通过建立带新版本号的案例并记录原因来更正。此前的 `LLM agent memory` 查询是在查看结果后才选择对照论文，因此只作为探索性诊断，不计入本次四题指标。查询的严格 AND 词项和 arXiv 原生排序造成的漏召回应如实记录，不能在同一批开发结果上调词后再包装成未见测试表现。
